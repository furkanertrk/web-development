# 🌐 Web Development Projects

Bu repo, **web geliştirme alanındaki öğrenme ve gelişim sürecimi** belgelemek için oluşturuldu.  
Frontend, backend ve full-stack alanlarında yaptığım tüm projeleri burada paylaşacağım.

---

## 🎯 Amaç
- Web geliştirme konusundaki ilerlememi adım adım takip etmek  
- Farklı teknolojileri deneyimleyerek portföyümü güçlendirmek  
- Öğrendiklerimi projelerle pekiştirip açık kaynak olarak paylaşmak  

---

## 🧰 Planlanan Teknolojiler
- **Frontend:** HTML, CSS, JavaScript, React.js  
- **Backend:** PHP, Node.js, Express  
- **Database:** MySQL, MongoDB, PostgreSQL  
- **Ek Araçlar:** Git, GitHub, REST API, JSON, AJAX  

---

## 🚀 Gelişim Yaklaşımım
Her proje, yeni bir kavram öğrenmek veya mevcut bir beceriyi geliştirmek için bir adım olacak.  
Bu repo, “öğrendikçe üret” felsefesiyle sürekli büyüyecek.
